# Загрузка изображений, шрифты и критический CSS

Изменения в исходниках от 6 ноября 2026. Форматы, качество, размеры и URL исходных изображений не менялись; конвертации и сервиса обработки изображений нет.

## Изображения

- Проверены все `<img>` в Vue-шаблонах. Добавлены `loading="lazy"` и `decoding="async"` в пропущенных блоках главной, корзине и мобильном меню, а также для дополнительных фото лайтбокса.
- Декоративный фон `.l-branded__img` использует прежний JPG через `<img loading="lazy">`. `object-fit: cover` сохраняет кадрирование.
- Изображения внутри CMS-страниц, описаний товаров/категорий и аккордеонов получают lazy-load через `withLazyImages` до отправки SSR HTML. Явные атрибуты автора сохраняются; `fetchpriority="high"` без `loading` получает `eager`.
- Главный баннер, первые четыре карточки каталога, основное фото товара и открытое фото лайтбокса загружаются сразу. Первой карточке каталога добавлен высокий приоритет.
- Используется нативный lazy-load: расстояние, на котором браузер начинает загрузку перед появлением изображения на экране, выбирает браузер.

## Montserrat

- Четыре статических начертания заменены на локальный вариативный Montserrat из `@fontsource-variable/montserrat` 5.3.0, ось веса 100–900, `font-display: swap`.
- Сохранены семейство `Montserrat` и все пять наборов символов. Через `unicode-range` браузер выбирает необходимые наборы.
- Латиница и кириллица предварительно загружаются из `<head>`. Их суммарный размер — 61 784 байта (60,3 КиБ) против 366 572 байт (358,0 КиБ) у прежних четырёх файлов. Дополнительные наборы загружаются, если на странице используются их символы, например знак гривны.
- Лицензия OFL: `public/fonts/montserrat-LICENSE.txt`.

## CSS

- `features.inlineStyles: true` встраивает глобальные стили и стили компонентов первого рендера в SSR HTML.
- Стили `CSpinner`, `CPageLoader` и страницы ошибки включены в глобальную таблицу: отдельных первоначальных запросов этих CSS больше нет.
- В проверенных SSR-ответах главной, категории и товара нет `<link rel="stylesheet">`. CSS модальных окон может загружаться при их открытии.

- `npm run test:unit` — 54 теста успешно, включая обработку CMS HTML.
